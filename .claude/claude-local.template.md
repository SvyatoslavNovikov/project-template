# Шаблон CLAUDE.local.md

`CLAUDE.local.md` в корне репозитория хранит личные правила Claude Code одного человека на одной машине. Файл в `.gitignore`, Claude Code подгружает его автоматически вместе с `CLAUDE.md`.

Сюда кладут только личное: кто работает, как к нему обращаться, особенности машины, личные доступы и привычки. Правила проекта, нужные агентам и коллегам, живут в `CLAUDE.md`: их должны видеть на любой машине.

## Как создать

На машине без файла хук `SessionStart` (`.claude/hooks/local_rules_check.py`) попросит Claude предложить создание. Claude:

1. Копирует блок ниже в `CLAUDE.local.md` в корне репозитория.
2. Заполняет то, что проверяется без вопросов: ОС и оболочка, путь к Python, какие переменные окружения из `.claude/hooks/config.json` (`secret_env`) заданы (только наличие, значения не читать и не печатать).
3. Остальное спрашивает у пользователя одним сообщением. Не угадывает: чего нет, остаётся `TBD`.
4. Показывает итоговый файл пользователю.
