# Environments

Справочник стендов и конфигураций прогона. Не тикеты: строки не получают `PRJ-<n>`.

- Добавить окружение: новая строка в таблицу.
- Указать в прогоне: ключ в поле `environment`.
- Указать на баге: ключ в поле `environment` (где воспроизвели).

| key | name | status | notes |
|---|---|---|---|

`status`: `active` | `archived`

Правила:

- `key` уникален и стабилен. Менять `key` нельзя — только `name`.
- Для новых прогонов не выбираем `archived`.
- Пустое `environment` допустимо только для чернового прогона.
