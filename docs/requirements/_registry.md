# ID Registry (requirements)

Сквозной счётчик `PRJ-<n>` только для артефактов в `docs/requirements/`
(epic, user-story, system-requirement, nfr, bug).

Справочники в `_catalogs/` номер не занимают. Тесты: [`docs/tests/_registry.md`](../tests/_registry.md).

| Поле | Значение |
|---|---|
| Last issued | 0 |
| Next | 1 |

Правило: взять **Next**, создать артефакт, затем сдвинуть оба поля.
