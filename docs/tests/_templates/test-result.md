# Результат кейса в прогоне

Файл называется по ID кейса, не получает собственный `PRJ-T-<n>`.
Ключ результата: `<id прогона> / <id кейса>`.

Кладём сюда только если не хватает строки в `results` файла прогона
(шаги, лог, ссылки на вложения). `defect` дублирует поле строки прогона.

---
case: PRJ-T-N
status: failed
comment: ""
defect: PRJ-N
---
