# confluence

CLI: `python scripts/confluence_cli.py`, запуск из корня репозитория. Настройки — `scripts/confluence.config.json`, токен — env `CONF_TOKEN` (не печатать, не вставлять в команды).

## Прочитать

```bash
python scripts/confluence_cli.py read "<ссылка или pageId>" --out tmp/agents/confluence/<pageId>.md
```

```bash
python scripts/confluence_cli.py search "space = ACME AND title ~ \"оплата\"" --limit 10
```

- Длинную страницу — в файл (`--out`), а не в чат; в основной поток — короткий пересказ со ссылкой на файл. Несколько страниц или большая — агентом (`general-purpose`, `model: sonnet`).
- Факты из страницы в требованиях — со ссылкой на страницу (ID или URL), как источник.
- Ссылка вида `/display/<space>/<title>` без pageId не поддерживается: найти страницу через `search` по заголовку.

## Опубликовать

1. Показать пользователю, что публикуем и куда (пространство, родитель), — dry-run:

```bash
python scripts/confluence_cli.py publish docs/meetings/2026-10-12-prj-12-onboarding.md
```

2. Только после его «да» — та же команда с `--apply`. Хук `external_write_guard` спросит подтверждение ещё раз: это не замена команде пользователя.
3. Артефакт `docs/` (есть `id` во frontmatter) публикуется как «<ID> <title>», ID страницы записывается в `external.confluence`, повторный publish обновляет ту же страницу. Обычный markdown создаёт новую страницу; обновить существующую — `--page-id`.

## Правила

- Источник правды — репозиторий: правки, сделанные прямо в Confluence, следующий publish перезапишет — предупредить пользователя. Если страницу правят люди, публиковать в новую или не публиковать.
- Пространство и родителя не угадывать: из конфига, из брифа или спросить.
- Вложения (картинки) CLI не загружает: нужны — сказать пользователю.
- Ошибка 401/403 — проверить, что `CONF_TOKEN` задан (без вывода значения) и `auth` соответствует серверу; 409 при создании — страница с таким заголовком в пространстве уже есть: найти её через `search` и обновить по `--page-id` с согласия пользователя.
