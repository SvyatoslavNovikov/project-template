# jira

CLI: `python scripts/jira_cli.py`, запуск из корня репозитория. Настройки — `scripts/jira.config.json`, токен — env `JIRA_TOKEN` (не печатать, не вставлять в команды).

## Прочитать

```bash
python scripts/jira_cli.py digest ACME-123
```

```bash
python scripts/jira_cli.py find "project = ACME AND text ~ \"оплата\" ORDER BY updated DESC" --limit 20
```

`digest` — кратко: тип, статус, исполнитель, связи, описание, последние комментарии. Сырой JSON задачи в чат не выводить. Много задач или длинные описания — читать агентом (`general-purpose`, `model: sonnet`), в основной поток — дайджест с ключами.

## Выгрузить артефакт

1. Артефакт проверен: `python .claude/hooks/docs_lint.py <файл>` без ошибок, пользователь посмотрел текст.
2. Dry-run и показать пользователю, что будет создано или обновлено:

```bash
python scripts/jira_cli.py publish PRJ-12
```

3. Только после его «да» — та же команда с `--apply`. Хук `external_write_guard` спросит подтверждение ещё раз: это не замена команде пользователя.
4. После создания CLI записывает ключ в `external.jira` артефакта. Изменение файла показать пользователю; коммит — по его команде.

Что уходит в Jira: `summary` — `title` артефакта, `description` — тело в разметке Jira со строкой «Источник: PRJ-<n>, путь», метка — ID артефакта. Тип задачи — `issue_types` в конфиге; тип, которого там нет (обычно SR и NFR), CLI не выгружает. У стори ставится Epic Link, если эпик уже в Jira и задан `epic_link_field`. Артефакт с `external.jira` обновляется (summary, description, метки), а не создаётся заново.

## Правила

- Источник правды — репозиторий. Правку текста делать в `docs/`, потом `publish`; правки, сделанные прямо в Jira, при следующем `publish` перезапишутся — предупредить пользователя.
- Статусы, исполнителей, спринты и версии CLI не меняет: это делают в Jira люди.
- Ключ в `external.jira` вручную не выдумывать: только из ответа Jira или со слов пользователя.
- Ошибка 401/403 — проверить, что `JIRA_TOKEN` задан (без вывода значения) и `auth` в конфиге соответствует серверу; ошибка 400 — показать текст ответа, поле не угадывать.
